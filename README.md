**轻量 · 本地优先的图像批量水印与快速辑录工具**

辑印（Albumark）把「给一批照片加水印、做基础调整、打包交付」压缩成一条流水线：
选择工作目录 → 建工作项目 → 批量导入 → 水印工作室 → 快速辑录 → 打包导出。所有图像处理都在本机
完成，**没有任何上传**，也没有账号与云端的负担。

## 功能

### 1. 工作目录与工作项目
- **两级结构**：先选一个**空文件夹**作为「工作目录」（软件自动校验为空），
  里面可以创建任意多个「工作项目」（子文件夹）；工作目录记录在软件数据里，下次启动直接进入
- **项目管理**：以卡片列出全部项目（名称 / 照片数 / 创建时间），一键新建、进入、删除，
  随时更换工作目录
- 每个项目是一个文件夹（`albumark.json` + `images/`），导入照片时逐批选择入库方式，
  **两种方式可在同一项目内共存**（缩略图以小图标区分）：
  - **复制**：照片原文件拷贝进项目，源文件增删不影响
  - **链接**：只记录源文件路径，并为内容生成**识别码**（SHA-256）；
    源文件失联时一键**重新定位**，识别码校对通过才重新链接
- **OOBE 首次引导**：软件数据位置可选，桌面便携版默认放在 **exe 根目录**（随 U 盘携带）
- 非桌面端提供本次会话的**临时项目**

### 2. 批量导入
- 拖入文件或**整个文件夹**（自动递归），或用选择器批量选取；仅支持 JPG；
  桌面端拖入走原生事件、直接拿文件路径
- 从**图片链接**批量导入（桌面端走 Tauri HTTP，不受浏览器跨域限制）
- 自动提取 EXIF 摘要：机型、镜头、光圈、快门、感光度、焦距、拍摄日期、作者
- 左下角信息栏：**张数 · 分辨率 · 文件名 · EXIF 摘要**

### 3. 水印工作室
- **完全独立的页面**：脱离照片制作水印，样张画布实时预览；
  制作结果以**预设**存入软件数据，工作区面板一键调用
- **文本图层**：字体（**自动读取系统字体**，按中文 / 西文 / 日文 / 韩文 / 等宽分类，
  也可手动输入）、**字重 100–900 无极调节**（可变字体完整生效）、颜色、字距、
  行高、对齐、斜体、**px 字号**、描边、阴影、**背景填充**
- **锚点定位**：九宫格锚点 + **距锚点像素距离**确定位置（画布显示锚点十字）；
  偏移按图片**长边**换算，横竖屏切换像素数值不变；样张与照片预览均可**直接拖动**水印，
  拖动时**吸附**中线 / 边距 / 其他图层并显示参考线（可在设置中开关）
- **图像图层**：自定义 SVG（矢量栅格化）与 PNG/JPG 贴纸，可随时替换
- **EXIF 令牌**：`{机型}`、`{光圈}`、`{拍摄日期}` 等，导出按每张照片替换；
  当前照片缺哪项，内容区**常驻警告**
- **碰撞箱贴合文字**：包围盒按真实字形度量，所见即所得
- **平铺整图**：间距可调，防裁剪盗用
- **模板**：内置「右下签名 / 全图平铺 / EXIF 参数条」，可保存自制模板

### 4. 快速辑录
曝光 · 亮度 · **对比度** · 高光 · 阴影 · 色温 · 色调 · 晕影，八项滑杆 -100~100，
外加**色调曲线**（可拖拽的控制点编辑器，单调样条插值）。双击滑杆名称复位单项，
**双击数值直接键入**精确值。默认应用到全部照片；对某张照片开启**单独调节**后，
它使用独立参数，不再应用全局调节。

### 5. 预览画布
- **分层渲染**：底图（解码 + 调节）由 Worker 合成缓存，水印叠加层主线程矢量绘制——
  改水印即时上屏，拖动水印只重绘叠加层，全程不掉帧
- PC 端**滚轮 / 触控板捏合**缩放，移动端**双指捏合**；双击在适应窗口与 250% 间切换；
  左下角**实时显示缩放值**；**最小缩放（安全区）可在设置中自定义**，
  预览内容也自动避开系统手势条等安全区
- 放大后可直接拖拽平移，**鼠标中键专用于平移**；到边界有橡皮筋回弹；
  放大时自动请求更高分辨率的精修渲染
- **← / → 方向键**顺序切换照片
- **预览性能档位**：高质量 / 均衡 / 省电，Android 等设备可按需调低

### 6. 操作面板与导出
- **悬浮操作面板**：**水印 / 调节 / 导出** 三个标签，主题色强调；可随时收起为右缘把手，
  进入工作区管理页面时自动收起；OOBE → 选目录 → 项目管理与面板切换均带**非线性过渡动画**
- 全部数值控件支持**双击键入**精确值
- JPEG 质量与长边限制（原图 / 2560 / 1920 / 1280 px）
- 文件名模板：`{name}` 原名、`{index}` 序号、`{date}` 日期 + EXIF 令牌，自动去重
- 导出方式：**ZIP 压缩包**（全平台）或**文件夹直写**（桌面端），并行渲染 + 进度条

## 技术与架构

```
src/
├─ core/        # 引擎：exif（EXIF 解析）· tokens（令牌替换）· adjust（像素管线）
│               # layout（图层几何 / 锚点）· draw（水印绘制）· renderer（Worker 通道）
│               # exporter（并行导出 + ZIP）· platform（Tauri/Web 能力适配）
├─ workers/     # render.worker：底图「解码 + 调节」合成；导出时叠加水印与 JPEG 编码
├─ stores/      # Pinia：workspace / images / watermark / presets / adjust / fonts
│               # templates / export / settings / toast
├─ components/  # 标题栏 · 工作区页面（OOBE/目录/项目）· 悬浮操作面板 · 预览画布（双层）
│               # 水印工作室 · 图层编辑器 · 曲线编辑器 · ui/ 原子组件
└─ styles/      # 设计令牌与基础样式（单一品牌橙 #FFA72F，深浅色自适应）
```

- 图像管线零服务器：预览与导出共用同一套 Worker 渲染代码，所见即所得；
  预览底图与水印叠加层分离，拖动水印零 Worker 往返
- 桌面端 Rust 侧仅两个自定义命令（`exe_dir` 便携版数据目录、`app_data_root` 兜底），
  其余走官方插件（dialog / fs / http / opener）；无边框窗口 + 前端自绘标题栏
- 运行时依赖只有 `vue` `pinia` `exifr` `fflate` `lucide-vue-next` 与 Tauri/Capacitor 官方包

## 开发

```bash
npm install
npm run dev        # 浏览器开发（http://localhost:5173）
npm run typecheck  # vue-tsc 类型检查
npm run build      # 类型检查 + 生产构建（输出 dist/）
```

### 桌面端（Tauri 2，需要 Rust 工具链）

```bash
cargo tauri dev    # 或：npm run tauri dev
cargo tauri build  # 产出安装包
```

### 安卓端（Capacitor）

`android/` 壳工程已随仓库提供（webDir 指向 `dist/`，不含任何编译产物）：

```bash
npm run build          # 先产出 Web 资源
npx cap sync android   # 同步 Web 资源与插件
npx cap open android   # 在 Android Studio 中构建运行
```

### 持续集成（GitHub Actions）

推送到 `main` 或打 `v*` 标签时自动构建，产物在 Actions 页面下载（支持手动触发）：

- **Windows x64 便携版**：单文件 exe（目标机器需系统自带的 WebView2 运行时）
- **macOS arm64**：`.dmg` 与 `.app`（未签名）
- **Android**：debug APK 可直接安装；release APK 未签名，需自行配置签名后发布

## 已知限制（v0.4.0）

- 仅支持 JPG 输入；导出为重编码 JPEG，**不回写 EXIF**（如需保留元数据请期待后续版本）
- 文件夹工作目录需要桌面端；安卓端为会话级临时项目
- 大体积 ZIP（数百张以上）在浏览器端会占用较多内存；桌面端后续改为流式写盘
- 读取系统字体依赖 Chromium 内核的 Local Font Access（WebView2 等），
  被拒或不支持时回退到常用字体清单，并可手动键入字体名
